## Setup and Installation

Prerequisites:
- Node.js 18 or higher
- Git

Install dependencies:

    npm install

Run lint:

    npm run lint

Run tests:

    npm test

Build project:

    npm run build

## CI/CD Deployment Process
GitHub Actions is used for Continuous Integration and Continuous Deployment.

The CI workflow runs linting, automated tests and the build process.

The deployment workflow automatically builds and deploys the application to
GitHub Pages when production changes are pushed to the main branch.

## Testing
Automated tests verify the main HTML file, required Todo interface elements,
and JavaScript application file.
